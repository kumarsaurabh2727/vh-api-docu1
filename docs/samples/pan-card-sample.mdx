# Pan Card
## Request Sample

```json
{
  "Front": "base64-encoded-front-image",
  "Back": "base64-encoded-back-image",
  "Source_type": "USER_UPLOAD",
  "Source": "MOBILE_APP",
  "Document_type": "PAN_CARD"
}
```

```json
{
  "RESPONSE": "SUCCESS",
  "RESPONSE_MSG": "PAN Card document processed successfully.",

  }
}
```
